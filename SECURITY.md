# Security

Report security problems in qos privately, through GitHub's private
vulnerability reporting:

https://github.com/Maruff/qos/security/advisories/new

Please do not open a public issue or discussion for them. Only the maintainer
sees a private report until a fix is released.

Say what is affected (the qos app, the `qos-setup` or `qos-desktop` scripts,
VS Code's sign-in, release signing or the qos F-Droid repository), how to
reproduce it, and your qos version, phone model and Android version.

Problems in qos Desktop go to its own form:
https://github.com/Maruff/qos-desktop/security/advisories/new

Packages installed with `pkg` come from the Termux package repositories, so
report problems in them to Termux: https://termux.dev/security
